# ⚔️ CYBER ARENA 1v1

가상 네온 그리드 위에서 펼쳐지는 **실시간 사이버 닌자 1대1 결투 액션 게임**.
별도 설치 없이 브라우저에서 바로 플레이할 수 있는 단일 HTML 파일 게임입니다.

🎮 **바로 플레이:** https://babburger7720-cloud.github.io/cyber_atena/

---

## 🕹️ 게임 모드

- **VS COMPUTOR (AI)** — 컴퓨터 닌자와 1대1 대결
- **LOCAL 2-PLAYER** — 한 키보드로 둘이서 대결

## 🎯 조작법

| | P1 (왼쪽) | P2 (로컬 2P, 오른쪽) |
|---|---|---|
| 이동 | `A` / `D` | `←` / `→` |
| 점프 | `W` | `↑` |
| 공격 | `F` | `K` |
| 방어(가드) | `G` | `L` |
| **대시** | `A` 또는 `D` **더블탭** | `←` 또는 `→` **더블탭** |

## ⚔️ 무기 (상성 존재)

| 무기 | 특성 | 메커니즘 |
|---|---|---|
| 🗡️ **CYBER KATANA** | 빠름 · 근접 | 검 **맨 끝자락**으로 베면 치명타 **15 데미지** 고정 |
| 🏹 **PLASMA BOW** | 원거리 · 무제한 사거리 | **20% 확률**로 1.5~2.5배 치명타 화살 발사 |
| 🔨 **GRAVITY HAMMER** | 느림 · 강력 | 데미지 **20** + 최고의 넉백, 충격파 가드 브레이크 |

> 가드 타이밍을 맞추면 근접 공격뿐 아니라 **원거리 화살도 막아낼 수 있습니다.**
> 가드 게이지가 바닥나면 스턴(CRASH) 상태가 되니 무한 방어는 금물.

## 💡 플레이 팁

- 카타나는 지형 발판 사이를 점프 무빙하며 끝자락 치명타를 노리세요.
- 활은 고지대 발판을 장악하고 대각선으로 화살을 퍼부어 접근을 봉쇄합니다.
- 해머는 공중 발판에서 하강 충격파로 가드를 부술 수 있습니다.

---

## 🛠️ 기술 스택

- 순수 **HTML5 Canvas** + **JavaScript** (프레임워크 없음, 의존성 0)
- 실시간 물리 엔진 (중력 · 넉백 · 발판 충돌)
- **Web Audio API** 기반 레트로 신디사이저 효과음 (사운드 파일 없음)
- Tailwind CSS (CDN) · Google Fonts (Orbitron / Oswald / Noto Sans KR)

## 🚀 로컬 실행

저장소를 클론한 뒤 `index.html`을 브라우저로 열기만 하면 됩니다.

```bash
git clone https://github.com/babburger7720-cloud/cyber_atena.git
cd cyber_atena
# index.html 더블클릭 또는 브라우저로 열기
```
